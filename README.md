# CZCLIENT 1.21.11

All-in-one Fabric client mod for Minecraft 1.21.11.

## Features
- Right Shift CZCLIENT menu
- Keystrokes HUD
- FPS and CPS HUD
- Coordinates HUD
- Armor HUD toggle
- Fullbright toggle
- Toggle Sprint
- Zoom toggle
- Custom CZCLIENT main menu
- Custom buttons and animated background
- GitHub Actions build that uploads the compiled JAR

## Build
Use Java 21. GitHub Actions automatically builds the mod on pushes to `main` or from Actions → Build CZCLIENT → Run workflow. The compiled JAR is uploaded as the `CZCLIENT-1.21.11` artifact.
